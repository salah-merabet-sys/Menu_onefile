Export & Deploy
Deploy to GitHub Pages

Make your changes in the Admin panel, then export a ready-to-push ZIP. Upload its contents to your GitHub repo and the public menu will show the latest data instantly — it always fetches a fresh copy of menu.json with no caching.

1
Edit your menu here in the Admin panel Add, update, or remove items. Upload images using the file picker in the item form.
2
Click "Export ZIP" below Downloads a ZIP containing the updated data/menu.json and any newly uploaded images in assets/images/.
3
Push to GitHub Extract the ZIP. Copy data/menu.json and assets/images/* into your repo. Commit & push. GitHub Pages deploys in ~30 seconds.
4
Done — customers see changes instantly The public menu always fetches a fresh menu.json on every page load, bypassing all browser and CDN caches.
